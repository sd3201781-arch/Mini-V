# AnimeHUB

A free mobile app for watching and discovering anime — browse **upcoming** and **past** seasons in one place.

> 🚧 **Status: early development.** This repository is just getting started; the app is being built.

---

## ✨ Planned features

- 📺 Browse **currently airing**, **upcoming**, and **past** anime
- 🔎 Search and filter by genre, season and year
- ⭐ Save favourites and build a watchlist
- 📝 Episode lists with titles and air dates
- 🌙 Clean, modern mobile UI

## 🛠️ Tech (planned)

- **Platform:** Android
- **Framework:** React Native / Expo
- **Language:** TypeScript / JavaScript

## 🚀 Getting started

Once the app code lands, you'll be able to run it with:

```bash
# install dependencies
npm install

# start the dev server
npx expo start
```

Then scan the QR code with the **Expo Go** app, or press `a` to launch an Android emulator.
